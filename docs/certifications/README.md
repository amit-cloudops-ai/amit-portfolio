## Credential accuracy and classification

The documents in this archive are AWS Training & Certification course or learning-plan completion certificates and training badges. They are **not** proof of passing a proctored AWS Certification exam. Do not describe these documents as “AWS Certified AI Practitioner” or “AWS Certified Cloud Practitioner”.

The “AWS Technical Accredited, Trained Partner” item is represented by a badge image, not a separate completion certificate in the supplied files.

## Archive conventions

- Preserve original AWS-issued PDF and badge content; only repository filenames and locations are normalised.
- Use lowercase descriptive filenames separated by hyphens.
- Add future credentials with the issuer's exact wording, completion date, evidence type and verification link.
- Never commit account credentials, passwords, tokens or webhook URLs.
